# Version 1.0.6 — Artist Hero Image

- Page-Hero-Blöcke unterstützen nun ein eigenes großes Bild.
- Bild kann im Block-Editor hochgeladen oder aus der Medienleiste auf den Block gezogen werden.

- Mobile Darstellung wechselt auf ein kompaktes 4:3-Format.
